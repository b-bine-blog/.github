## 프로젝트

**b-bine blog** — 회원이 자기 블로그를 만들거나 다른 블로그에 참여해 함께 운영하는 블로그 플랫폼

- 블로그장·부블로그장·멤버는 계정 종류가 아니라 블로그마다 정해지는 역할
- 글(마크다운)·카테고리·태그·댓글·좋아요, 통합 검색, 메인 피드
- 팔로우·구독·알림, 신고·제재, 관리자 화면
- 다크 모드, 시간대에 따라 바뀌는 사이트 색
